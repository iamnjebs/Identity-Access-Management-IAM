# Identity-Access-Management-IAM

# Expected Lab Outcomes
By the end of this lab, you should have:
✅ Created IAM Users
✅ Created an IAM Group
✅ Attached an AWS Managed Policy
✅ Assigned users to a group
✅ Explored IAM Policies
✅ Understood MFA configuration
✅ Created an IAM Role for EC2
✅ Applied the Principle of Least Privilege
✅ Practiced AWS identity security best practices
